# 點餐明細系統

一個放在瀏覽器裡就能用的小工具：輸入菜單上的品項編號，就自動列出訂單明細、每項金額、總份數和總金額。適合團體訂餐、統計便當份數的人使用。

## ⬇️ [點這裡下載最新版](../../releases/latest/download/food-order.html)

下載後直接**雙擊開啟**（會用你的瀏覽器打開），不用安裝、不用登入。

## 這個程式能做什麼

- 輸入品項編號就能加入訂單，一次可輸入多筆，例如 `7-8-9-10`（用 `-`、逗號或空白分隔都可以）
- 自動算出每個品項的單價、小計、總份數與總金額
- 有大份／小份的品項，預設加入「大份」，加入後可在訂單明細裡按一下切換大或小
- 也可以直接點菜單卡片上的 ＋／－ 調整數量
- 「僅複製品項與數量」：只複製品項名稱和份數（不含價格），方便貼給店家或群組
- 「存入歷史紀錄」：把整張訂單存起來，之後可以展開查看或刪除

## 使用前需要準備什麼

- 電腦或手機都可以，只要有瀏覽器（Chrome、Edge、Safari、Firefox 等）
- 不需要安裝任何東西，也不需要註冊帳號

## 怎麼開始使用

1. 點上方的「點這裡下載最新版」，下載 `food-order.html`。
2. 在下載的檔案上**雙擊**，用瀏覽器開啟。
3. 在最上方的「編號」欄輸入品項編號，例如 `4`，按「加入清單」。想一次加多個就輸入 `7-8-9-10`。
4. 看「訂單明細」：會列出每個品項、單價、小計，最下面是總份數與總金額。
5. 有大小份的品項，可以在明細中按「大」或「小」切換。
6. 要把訂單貼給別人，按「僅複製品項與數量」，再到聊天軟體貼上。
7. 訂單確認後，按「存入歷史紀錄」保存，並自動清空清單，準備下一筆。

## 常見問題

**開啟後畫面沒有出現？**
請確認是用瀏覽器開啟，而不是用記事本或其他文字編輯器。

**在手機上複製沒有反應？**
部分手機瀏覽器會擋掉自動複製。這時畫面會跳出一個文字框，長按文字選取全部再複製即可。

**下載連結打不開（顯示 404）？**
代表這個專案目前沒有公開，請向專案擁有者索取檔案。

**歷史紀錄不見了？**
歷史紀錄存在你目前使用的瀏覽器裡。換了瀏覽器、換了裝置，或清除了瀏覽器資料，紀錄就不會跟過去。

## 注意事項

- 所有訂單與歷史紀錄都只存在你自己的瀏覽器，**不會上傳到任何伺服器**。
- 頁面會向 Google Fonts 載入網頁字型；沒有網路時會自動改用系統內建字型，功能不受影響。
- 菜單品項與價格是寫在程式裡的，如果店家調整菜單，需要更新程式內容。
