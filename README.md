# 點餐明細系統

一個放在瀏覽器裡就能用的小工具：輸入菜單上的品項編號，就自動列出訂單明細、每項金額、總份數和總金額。適合團體訂餐、統計便當份數的人使用。

## 🌐 [直接開啟網頁版（iPhone、Android、電腦都適用）](https://TYwry.github.io/food-order-system/)

點開連結就會在瀏覽器裡使用，不用下載、不用安裝、不用登入。

**iPhone 用戶：** 用 Safari 開啟上面的連結，點下方的分享按鈕，選「加入主畫面」，之後就能像 App 一樣從主畫面點開使用。

## ⬇️ [下載檔案版（電腦用）](../../releases/latest/download/index.html)

下載後雙擊 `index.html`，會用電腦的瀏覽器開啟。

## 這個程式能做什麼

- 輸入品項編號就能加入訂單，一次可輸入多筆，例如 `7-8-9-10`（用 `-`、逗號或空白分隔都可以）
- 自動算出每個品項的單價、小計、總份數與總金額
- 有大份／小份的品項，預設加入「大份」；在訂單明細裡大份、小份各有自己的 −／＋，可以分開調整，例如一份大、兩份小
- 也可以直接點菜單卡片上的 ＋／－ 調整數量
- 上方的搜尋欄：輸入關鍵字即可篩選菜色，符合的品項都會顯示，一樣可以直接加入清單
- 「清空訂單明細」：把目前的清單清空，不會留下任何紀錄（按下去會先詢問一次，再按一次才會真的清空，避免手滑）
- 「複製品項與數量」：只複製品項名稱和份數（不含價格），方便貼給店家或群組
- 「直接加入日曆」：把目前的訂單存到日曆，預設使用當天日期
- 「更改日期並儲存」：選擇年、月、日後，把目前的訂單存到日曆的指定日期（用來補登之前的訂單）
- 「貼上舊訂單」：貼上先前複製的「品項 x數量」文字，會自動解析並加入訂單明細，再用上面兩個按鈕存檔
- 日曆資料超過 1 年會自動清除，不需要手動整理，也不用擔心佔用太多空間
- 「清空輸入文字」：在「貼上舊訂單」區塊裡，一鍵清空貼上的文字內容
- 「複製今日金額」：選一個 1 到 9 的數字（預設 9），按下去會複製「午＋數字，今天已加入日曆的總金額」這段文字，例如「午9，770」
- 右上角的 📅 日曆：點開可查看每天點的菜色與金額，並自動顯示每個月的總金額

## 使用前需要準備什麼

- 手機或電腦都可以，只要有瀏覽器（Safari、Chrome、Edge、Firefox 等）
- 不需要安裝任何東西，也不需要註冊帳號

## 怎麼開始使用

1. 點上方的「直接開啟網頁版」連結（電腦也可以改用下載檔案版）。
2. 在最上方的「編號」欄輸入品項編號，例如 `4`，按「加入清單」。想一次加多個就輸入 `7-8-9-10`。
3. 看「訂單明細」：會列出每個品項、單價、小計，最下面是總份數與總金額。
4. 有大小份的品項，明細裡大份、小份各一列，用各自的 −／＋ 調整數量。數量是 0 的那一列會變淡，按 ＋ 就能再加回來。
5. 要找某個品項，可以在菜單最上方的搜尋欄輸入關鍵字，符合的品項都會顯示出來。
6. 要把訂單貼給別人，按「複製品項與數量」，再到聊天軟體貼上。
7. 訂單確認後，按「直接加入日曆」保存（用當天日期），或按「更改日期並儲存」選擇其他日期保存，存檔後清單會自動清空，準備下一筆。
8. 想補登之前的訂單：展開「貼上舊訂單」，貼上先前複製的文字並按「解析並加入明細」，再用「直接加入日曆」或「更改日期並儲存」保存。
9. 想查詢某天或某個月花了多少錢：點右上角的 📅，用「‹」「›」切換月份，上面會顯示當月總金額；點日期上有紅色標記的格子，下方會列出那天點的菜色和金額。
10. 想清空目前還沒存檔的清單，按「清空訂單明細」即可，不會留下任何紀錄。

## 常見問題

**網頁版打不開，顯示 404？**
剛發布的網頁版需要等 1 到 2 分鐘才會開通，請稍後重新整理。

**iPhone 下載檔案後跑到「檔案」App，打不開網頁？**
iPhone 會把下載的 HTML 檔放進「檔案」App，不會直接用 Safari 開啟。請改用上方的「網頁版」連結。

**在手機上複製沒有反應？**
部分手機瀏覽器會擋掉自動複製。這時畫面會跳出一個文字框，長按文字選取全部再複製即可。

**日曆裡的紀錄不見了？**
紀錄存在你目前使用的瀏覽器裡。換了瀏覽器、換了裝置，或清除了瀏覽器資料，紀錄就不會跟過去。iPhone 的 Safari 可能會清掉長時間沒開啟的網站資料，建議用「加入主畫面」的方式開啟。

## 注意事項

- 所有訂單與歷史紀錄都只存在你自己的瀏覽器，**不會上傳到任何伺服器**。
- 網頁版與程式碼是公開的，任何人都可以開啟使用，但看不到別人的訂單。
- 頁面會向 Google Fonts 載入網頁字型；沒有網路時會自動改用系統內建字型，功能不受影響。
- 菜單品項與價格是寫在程式裡的，如果店家調整菜單，需要更新程式內容。
